# Font Installation Instructions

## For Tarkov Menu (Bender Font)

1. Download the Bender font from: https://www.1001fonts.com/bender-font.html
2. Convert to WOFF/WOFF2 format if needed (use online converters like fontsquirrel.com)
3. Place the font files in `/workspace/public/fonts/`:
   - `Bender.woff2`
   - `Bender.woff` (optional fallback)

## For Blue Archive Menu (Noto Sans JP)

This font is automatically loaded from Google Fonts CDN, no manual installation needed.

## Game Assets

### Tarkov Assets
Download from the repositories you linked and place in `/workspace/public/assets/tarkov/`:
- `bg_main.jpg` - Main menu background image
- `operator.png` - Operator character image (transparent PNG)
- `noise.png` - Optional noise/scanline overlay texture

Sources:
- https://github.com/RatScanner/EfTIcons - For icons
- https://github.com/the-hideout - For UI elements
- https://github.com/tarkovtracker-org/TarkovTracker - For additional assets
